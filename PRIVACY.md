# Vstavka privacy policy

Publisher: **Horoko**  
Effective date: **September 6, 2026**  
Privacy questions: [Vstavka support on GitHub](https://github.com/Xopoko/vstavka-support/issues/new/choose). This is a public channel; do not include private information.

## Clipboard information

After you choose **Enable history**, Vstavka processes supported changes to your Windows clipboard so you can view, search, and paste previous items. This can include text, links, color values, images, copied file names and paths, the time of a copy, and the available name of the source application. Clipboard information may contain personal or sensitive data that you choose to copy.

File entries store paths, not backup copies of the files. Vstavka also saves your language, appearance, sound, retention, application-exclusion, and startup preferences locally. It does not read the clipboard contents already present when the app launches.

## Local storage and security

Clipboard history and settings are stored in your Windows user profile on your PC. The history file is encrypted using the Windows Data Protection API for your Windows account. Items are decrypted in memory when the app uses them. This does not protect against software already running with access to your Windows account or someone using your unlocked Windows session.

Vstavka does not send clipboard contents, history, searches, or usage statistics to the developer. It has no accounts, advertising, analytics, or cloud synchronization. Link previews do not download website content. Microsoft Store acquisition and updates are handled by Microsoft under Microsoft's own terms and privacy practices.

## Your controls

You can pause history saving, exclude source applications, delete individual items, clear history, and change the available retention settings. By default, history retains up to 500 items for 30 days. Pinned items are kept beyond these age and count limits until you unpin or delete them, subject to the app's storage limits.

Vstavka honors supported clipboard privacy markers and its excluded-application list. It cannot reliably identify all passwords or secrets copied as ordinary text. Pause saving or exclude a sensitive application before copying content you do not want in history. A copy sound may play for an excluded clipboard change without reading or saving its content. Optional paste sounds recognize paste shortcuts; the app does not record what you type.

Deleting an item or clearing history does not delete original files, the separate Windows clipboard, other applications' data, or copies you have already pasted. It is not a promise of secure physical erasure or removal from operating-system backups.

## Pasting and support

When you select an item for copying or pasting, Vstavka places it on the Windows clipboard. When you request a paste, it asks the previously active application to paste. The receiving application then handles that content under its own practices.

Support is provided through public GitHub issues. Submitting an issue requires a GitHub account. The publisher can read the GitHub username, issue text, comments, and attachments that you voluntarily submit and use them to investigate and respond to your request. These contributions are also visible to others on the public repository. Include only the app version, Windows version, and a description using harmless sample data. Do not post clipboard history, passwords, tokens, private documents, or screenshots containing personal information.

GitHub hosts the support repository and handles accounts, support-page visits, and submitted content under its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). GitHub issues are separate from the Vstavka app: the app does not automatically upload diagnostics or open support requests. If you need a public support contribution corrected or removed, identify the contribution without repeating the sensitive information. Public content may already have been copied by others; removal is not a guarantee that every copy will disappear.

## Changes

The publisher will update this policy and its effective date if the app's data practices change. Questions about this policy can be sent to the privacy contact above.
