# Vstavka support

Publisher: **Horoko**  
Support: [Open a GitHub issue](https://github.com/Xopoko/vstavka-support/issues/new/choose).

Issues are public and require a GitHub account. Use harmless sample data; do not post clipboard history, passwords, tokens, private documents, or screenshots containing personal information.

Vstavka is a free clipboard history app. It runs on macOS 13 or later and on Windows 11 on x64 PCs. History stays on your device.

## macOS

1. Open Vstavka and follow the setup guide. When macOS asks about clipboard access, choose **Always Allow** to save new copies while Vstavka runs in the background.
2. Copy some sample text, switch to the app where you want it and press **Shift–Command–V**. You can also open history from the Vstavka menu bar icon.
3. Use the arrow keys to select a card. In the Mac App Store version, press **Enter** to copy the item, then **Command–V** in the destination app. The macOS preview can paste for you if you grant it Accessibility access.

If the copy is missing, check whether saving is paused or the source app is excluded. On versions of macOS that offer clipboard controls, confirm Vstavka has access under **System Settings → Privacy & Security → Clipboard**. Apps may mark some copies as private. Vstavka skips copies with supported privacy markers.

**Settings** lets you change the shortcut, adjust retention, exclude apps or clear history. You can also pause saving from the menu bar icon. File entries remember paths to the original files. Text entries keep plain text.

## Windows

### Open and paste

Launch Vstavka from Start and select **Enable history** on first run. Copy something new, then press **Ctrl+Shift+V** to show the panel. Select a card and press **Enter**, or double-click it, to paste into the app you were using. **Shift+Enter** pastes plain text or file paths. **Escape** hides the panel.

If the shortcut is already used by another program, choose **Alt+V** or **Ctrl+Alt+V** in Vstavka Settings. The notification-area icon also opens the panel and Settings.

### Missing entries or paste issues

Check whether saving is paused or the source application is excluded. Some applications mark their copied content as confidential; Vstavka skips supported privacy-marked content. It only saves new supported clipboard changes after history is enabled.

File cards remember paths. If a file was moved or deleted, Vstavka cannot restore it. Text is saved without its original formatting. An app running as administrator may block automatic paste from Vstavka; copy the selected item and paste manually into the destination.

### Sounds and appearance

Copy and paste sounds have separate switches and a shared volume control. Check the Windows volume mixer and your audio output if a sound is missing. Ordinary Ctrl+V and Shift+Insert sounds indicate the shortcut, not confirmation that the destination accepted the content. Paste commands in other applications' menus are not detected.

Settings includes light, dark, and system themes, accent colors, and the interface language. You can also choose whether Vstavka starts after you sign in to Windows.

## History and privacy

Pause saving from the history panel or app menu. Delete a selected item, or clear history from Settings. Clearing Vstavka's history leaves the system clipboard, original files and copies already pasted into other apps in place.

History is encrypted and stays on your device. Read the [privacy policy](https://github.com/Xopoko/vstavka-support/blob/main/PRIVACY.md) for details about local storage and public support requests.

## Report a problem

When you [report a problem](https://github.com/Xopoko/vstavka-support/issues/new/choose), include the app version, your macOS or Windows version and the steps that led to the problem. Use a harmless sample and leave out clipboard history, passwords, tokens and private documents. To close Vstavka, choose **Quit** in its macOS menu bar menu or **Exit** in the Windows notification-area menu.
