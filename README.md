# Vstavka support

Publisher: **Horoko**  
Support: [Open a GitHub issue](https://github.com/Xopoko/vstavka-support/issues/new/choose).

Issues are public and require a GitHub account. Use harmless sample data; do not post clipboard history, passwords, tokens, private documents, or screenshots containing personal information.

Vstavka is a free clipboard-history app for Windows 11 on x64 PCs. It works locally and does not require an account.

## Open and paste

Launch Vstavka from Start and select **Enable history** on first run. Copy something new, then press **Ctrl+Shift+V** to show the panel. Select a card and press **Enter**, or double-click it, to paste into the app you were using. **Shift+Enter** pastes plain text or file paths. **Escape** hides the panel.

If the shortcut is already used by another program, choose **Alt+V** or **Ctrl+Alt+V** in Vstavka Settings. The notification-area icon also opens the panel and Settings.

## Missing entries or paste issues

Check whether saving is paused or the source application is excluded. Some applications mark their copied content as confidential; Vstavka skips supported privacy-marked content. It only saves new supported clipboard changes after history is enabled.

File cards remember paths. If a file was moved or deleted, Vstavka cannot restore it. Text is saved without its original formatting. An app running as administrator may block automatic paste from Vstavka; copy the selected item and paste manually into the destination.

## Sounds and appearance

Copy and paste sounds have separate switches and a shared volume control. Check the Windows volume mixer and your audio output if a sound is missing. Ordinary Ctrl+V and Shift+Insert sounds indicate the shortcut, not confirmation that the destination accepted the content. Paste commands in other applications' menus are not detected.

Settings includes light, dark, and system themes, accent colors, and the interface language. You can also choose whether Vstavka starts after you sign in to Windows.

## History and privacy

Pause saving from the panel or notification-area menu. Delete a selected item, or clear the history from Settings. Clearing Vstavka's history does not clear the separate Windows clipboard, original files, or copies already pasted into other apps.

History stays on your PC and is encrypted for your Windows account. Vstavka does not have cloud sync, accounts, ads, or analytics. Read the [privacy policy](https://github.com/Xopoko/vstavka-support/blob/main/PRIVACY.md) for details, including how voluntary public support requests are handled by GitHub.

## Report a problem

Include the Vstavka version, Windows version, and the steps that led to the problem. Use a harmless sample to reproduce it. Do not attach clipboard history, passwords, tokens, or private documents. To exit the app fully, choose **Exit** from its notification-area menu.
